- First successful advanced edit promotes schema + marker + edit atomically.
- Opening, previewing, rendering, normal saving, AI/Random, or Copy Scene Animations never implicitly promote v3.
- Normal Save cannot downgrade an existing v4 file to v3.
- First v3→v4 overwrite creates non-clobbering `.pre-schema-v4.bak`.
- FFmpeg remains the final/reference renderer.
- Existing v3 render path and all 21 native effects are the regression baseline.
